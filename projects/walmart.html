Walmart Operations Analytics

Analysis of store operations and how Nil Picks impact performance.

EXCEL POWER BI DATA ANALYTICS
/ PROBLEM

What needed solving

High NIL Pick (Not-In-Location Pick) activity reduces fulfillment efficiency and indicates underlying inventory management issues. This project investigates the operational impact that NIL Picks have using real Walmart store data.

/ DATASET

The data

Data was collected from Walmart's MyWalmart application, including fulfillment KPIs, freight activity, inventory metrics, NIL Picks, and Out Scans. The data was consolidated and prepared for analysis in Excel.

/ APPROACH

How I tackled it

I cleaned and organized the data in Excel, developed KPI calculations and Pivot Tables, and built an interactive Power BI dashboard to analyze operational performance and identify improvement opportunities.

/ RESULTS

What came out of it

The analysis highlights operational trends affecting fulfillment performance and provides recommendations to improve inventory execution, freight prioritization, and overall store efficiency.
